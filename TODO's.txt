UI Design & Styling Guidelines

Visual reference: Claude Code desktop (dark theme).

These guidelines establish a consistent visual foundation, not a strict design specification. Use the reference as inspiration and refine individual elements as needed. Usability, readability, and user preferences take precedence.

General Style

Minimalist, modern, professional developer-tool aesthetic.

Dark, neutral surfaces with subtle contrast and restrained accents.

Content-focused design with minimal visual clutter.

Prefer flat surfaces over gradients, heavy shadows, or decorative effects.

Keep navigation compact while allowing the main content room to breathe.

Colors

Suggested starting palette (adjustable):

Main background: #151515

Sidebar: #111111

Elevated surfaces/inputs: #202020

Hover/selected surfaces: #292929

Borders/dividers: #303030

Primary text: #F2F2F2

Secondary text: #A0A0A0

Muted text: #737373

Use accent colors sparingly: blue for active states, green for success, red for errors, and orange for warnings. Colors are examples, not fixed requirements.

Typography

Neutral sans-serif (Inter or system UI); monospace for code and technical content.

Body: ~13–14px; headings: ~14–16px; metadata: ~11–12px.

Prefer regular/medium weights, using semibold selectively.

Establish hierarchy through contrast, weight, and spacing rather than oversized text.

Layout & Components

Suggested spacing scale: 4/8/12/16/24px.

Subtle 1px borders and moderately rounded corners (~6–10px).

Compact toolbars, sidebars, inputs, and navigation.

Comfortable reading width and spacing in content areas.

Selected items should be distinguishable without overly bright backgrounds.

Prefer simple outline icons (~16–18px).

Use collapsible panels and progressive disclosure for secondary information.

Keep scrollbars unobtrusive.

Interaction & Accessibility

Subtle hover/focus transitions (~120–180ms).

Avoid unnecessary animations or distracting visual effects.

Provide clear loading, disabled, selected, and error states.

Maintain sufficient text contrast, visible keyboard focus, and responsive layouts.

Respect reduced-motion preferences.

Consistency & Iteration

Reuse shared design tokens and components wherever practical.

Follow established patterns unless there is a clear reason to improve them.

Styling values are adjustable defaults, not mandatory constraints.

User-approved styling decisions override these guidelines.

Refine individual components without unnecessarily redesigning unrelated UI.

New components should complement the existing interface without requiring identical styling.

Core principle: Maintain a cohesive, minimalist visual identity while allowing continuous, targeted refinement based on functionality and user feedback.
