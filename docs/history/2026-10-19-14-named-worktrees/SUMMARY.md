# Named worktrees, grouped sessions

User requests (2026-10-19): the app project has no ⋯ menu (no Remove, no Archive); the worktree dropdown ("New worktree" plus the existing ones) sits left in the Send row with a name field for a new worktree, whose name is also its branch; empty, invalid or taken names get a message; the sessions list groups the app project's chats under one heading per worktree.
