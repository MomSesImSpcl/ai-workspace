# Details

Trigger: discussion of prompt-cache cost. An idle process costs nothing; a message after the cache lifetime re-bills the full transcript, whether the process lived or the session was resumed. The user asked for a feature covering cold-session warnings that depend on the subscription, a guard like the cache-tax plugin, and an optional onboarding step.

Checks: both feature files exist; the overview, traceability index and integration matrix point to them; links to onboarding-002/009/010, orchestrator-006 and ADR 0008 resolve to existing files. Open decisions: keep-warm pings, setting scope, default threshold.
