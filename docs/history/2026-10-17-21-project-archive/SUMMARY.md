# Project archive

Projects can be archived and restored from a ⋯ / right-click menu on the Projects page, with a styled confirmation for Archive and a "Show archived" toggle. Decided with the user: archive is the only removal; the workspace never deletes a project, its folder or its history (identity-projects 1.4). Project ids with spaces now work in the API. The confirmation dialog now resolves from its buttons directly (its `close` event is paused in hidden windows). Tests 31/31; checked in the browser pane.
