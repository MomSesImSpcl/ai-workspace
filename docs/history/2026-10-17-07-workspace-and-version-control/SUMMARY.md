# Workspace defined; version control feature specified

A workspace is the app on one computer; projects are local folders that go online through their own version control ([identity-projects 1.4](../../features/identity-projects/SPEC.md#14-workspace-and-local-projects)). Project rules live in the project folder and travel with it; sessions, tasks and audit stay in workspace storage. New feature [version-control](../../features/version-control/SUMMARY.md): clone, changes, commit, pull/push, history, branches from the UI, Git first. Specification only.
