# Workspace export and import

New feature [workspace-transfer](../../features/workspace-transfer/SUMMARY.md), agreed with the user: part 1 (transfer-001–006) built, part 2 private encrypted Git sync (transfer-101–105) specified only, because it needs an ADR relaxing "never synced" (identity-projects 1.4). Settings → Workspace storage has Export… (privacy warning, save dialog) and Import… (open dialog, result per project). The file is gzip JSON (`.aiworkspace`, standard library only); credentials (the Codex home), runner files and view state are never exported; import merges by id without overwriting, keeps local settings and audit, links projects to their original folder or a same-named folder in the workspace folder, else adds them archived; unknown versions and entries outside storage are rejected before anything is written.

Checks: `npm test` 37/37 (two new transfer tests: full round trip with folder mapping, idempotent second import, exclusions; rejection of foreign files, versions and five unsafe paths). Real round trip: the user's storage exported read-only (19 files) and imported into an empty test workspace: 2 sessions and 5 tasks, as in the source; the test files were deleted. Desktop dialogs not clicked in the Electron window. Branch `claude/chat-sessions-per-project-f82af3`.
