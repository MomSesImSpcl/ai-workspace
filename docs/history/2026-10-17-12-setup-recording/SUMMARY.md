# Setup steps recorded in one place

The [dependency inventory](../../DEPENDENCIES.md#setup-order-on-a-new-machine) now has an ordered setup list for a new machine and records every one-time user step (Codex Windows sandbox, Electron download fallback, Start menu shortcuts). The README links to it, the working agreement requires recording setup steps in the same commit, and onboarding gains onboarding-007 (per-agent setup gaps such as Codex's disabled Windows sandbox).
