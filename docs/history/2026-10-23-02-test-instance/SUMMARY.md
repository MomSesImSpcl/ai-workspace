# Test instance of a branch (selfdev-009)

The branch heading in the app project's session list gets **Open test instance**: the branch's own code as a second window with its own storage, a copy of the main instance's settings, no update buttons and the title `Test Branch - <branch>` ([selfdev-009](../../features/self-development/SPEC.md#requirements), [ADR 0020](../../architecture/decisions/0020-test-instance.md)). Typecheck clean, tests 108/108, started for real on Windows next to the running app. The menu in the app itself is not yet tried.
