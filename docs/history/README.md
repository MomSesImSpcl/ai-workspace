# Development history

One folder per completed work item: `YYYY-MM-DD-NN-short-name/` with `SUMMARY.md` (a few lines: scope, outcome, status) and `DETAILS.md` (checks, evidence, limitations, branch/commit). `NN` orders items within a day.

Read [current progress](../PROGRESS.md) first. Scan summaries by folder name or keyword and open details only when relevant. Entries describe their recorded time and do not authorize present work. Follow the [history contract](../WORKING_AGREEMENT.md#progress-and-history) for new entries.
