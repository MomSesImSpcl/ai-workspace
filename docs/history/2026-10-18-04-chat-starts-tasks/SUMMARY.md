# A chat starts tasks (sessions-002)

A chat's agent starts background tasks with the workspace `start_task` tool; the task records its chat, and the chat shows it inline with its approvals, reply field and result. The Task Center shows details and Cancel only; the stopgap start form, resume and reply there are removed ([ADR 0010](../../architecture/decisions/0010-tasks-started-from-chat.md)). Built, tested with fake agents, not yet run with the real agents; merged into `main` 2026-10-18. Same branch: [ADR 0011](../../architecture/decisions/0011-orchestrator-works-through-tasks.md) (orchestrator chat runs all work as uncapped tasks, orchestrator-006) and the per-run-only switch rule in orchestrator-005, specified only. See [details](DETAILS.md).
