# Accent colour setting specified

The user wants a future Settings option for the accent colour while keeping the warm palette for now. Specified as desktop-002 in [desktop-client](../../features/desktop-client/SPEC.md#21-desktop-client): preset swatches plus a custom picker (user's choice), one colour derives the `--accent*` token family with WCAG contrast checks, stored as a UI pref, applied without restart. Not built; traceability marks it `not-started`.
