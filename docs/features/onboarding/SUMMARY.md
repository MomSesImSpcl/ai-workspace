# Agent setup onboarding and readiness in the UI

**Status:** not-started

Make it obvious in the desktop app which agents exist, which are ready to use, and what each role needs. Any agent can run any role, so no agent CLI is required up front, but at least one must be installed and logged in. A first-start setup step, plain-language role settings and a readiness check in the task composer explain this where the user decides, without failed tasks. Status comes from the distribution prerequisite check.

[Full requirements](SPEC.md).
