[Shared principles](../../PRINCIPLES.md) apply.

## 2.3 Notifications

- Notify a user when a task needs input, finishes, fails, is blocked by permissions/resources or exceeds its budget. Desktop and mobile should reflect consistent task state.
- Support notification preferences, quiet periods where appropriate, and privacy-safe previews (no unauthorized repo data in push notifications).
