# Documentation authoring and maintenance by agents

**Status:** not-started

Rules agents follow whenever they create or change code and its documentation: document intent and contracts, use searchable domain wording and resolvable links, keep specs, comments, ADRs and evidence apart, stay proportional and truthful, and update affected docs in the same change. Format-neutral, so each project keeps its own conventions. Once documentation indexing is built, existing code and docs are documented to these rules in reviewed, proportional passes.
