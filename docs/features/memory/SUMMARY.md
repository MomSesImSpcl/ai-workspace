# Automatic long-term memory and project knowledge

**Status:** not-started

Capture useful durable knowledge into scoped, versioned memories with provenance. Detect conflicts, consolidate incrementally and inject selectively across authorized agents. Users control retention; memory remains subordinate to current verified evidence.

[Full requirements](SPEC.md).

Hindsight-specific qualification is tracked separately in [Hermes Agent and Hindsight evaluation and integration](../hermes-hindsight/SUMMARY.md); its use case and adoption remain open.

**Dependencies / related features:** [ai-orchestrator](../ai-orchestrator/SUMMARY.md), [knowledge-retrieval](../knowledge-retrieval/SUMMARY.md), [identity-projects](../identity-projects/SUMMARY.md).
