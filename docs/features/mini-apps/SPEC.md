## 6.4 Proofs / mini-apps / task dashboards

- Support optional generated interactive mini-tools within the workspace as review/analysis surfaces: economy simulator, boss editor, asset browser, quest graph, IP similarity review, benchmark dashboard, video-production tracker, performance viewer, etc.
- Generated UI/code executes with constrained permissions; it cannot bypass task, data or tool policy just because it appears inside a workspace panel.
- Domain templates are add-on examples, not special cases inside the core.
