# Project history and selective progress retrieval

Preserve development outcomes, decisions, handoffs and verification while loading only current state and relevant history into agent context. The repository starts with a compact progress file and searchable monthly Markdown archives. This future feature evaluates JSONL for structured events and SQLite for transactional records or a rebuildable query index, with explicit switching criteria, provenance, scoped retrieval and reversible migration. Formats remain candidates; no database, event pipeline or migration tooling is implemented or selected.

[Full requirements, tradeoffs and switching criteria](SPEC.md).
