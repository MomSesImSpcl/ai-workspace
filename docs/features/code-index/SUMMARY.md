# Semantic code indexing and change-aware knowledge

**Status:** not-started (specified: language analysis code-index-001–028; documentation indexing and code linking code-index-030–039, 2026-10-19)

Index symbols, relationships, tests and Git changes, through per-language adapters: TypeScript/JavaScript, HTML/CSS, Markdown, JSON/YAML, shell and batch first, in that order (including links between markup, styles and handlers, section retrieval from docs, config lookup by key path, and script diagnostics without running anything), compiler-backed C# later. Find internal code and approved dependencies before proposing replacements; keep documentation grounded in current, authorized source. Documentation in any format links both ways to the code it describes, through pluggable documentation adapters.
