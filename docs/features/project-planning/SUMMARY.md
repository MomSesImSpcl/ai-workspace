# Project planning, wiki and public roadmap

**Status:** not-started

Link project features and tasks to reusable, long-form wiki pages, with stable references, revision history and clear distinctions between proposals, approved intent and verified behavior. Supply authorized, traceable context to the configured orchestrator and optionally publish reviewed public snapshots through a read-only roadmap/wiki portal. Planning, pages and publishing remain separable and portable across code and non-code projects. This is a concept feature definition; technologies, initial slice and delivery order remain undecided.
