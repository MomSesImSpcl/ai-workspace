# Identity, projects and repository access

**Status:** in-progress: local project registry only, no identity or auth (core slice 1)

Authenticate users, group code or non-code resources into projects, and enforce repository access throughout the workspace. Separate content visibility from privileged actions; support auditable collaboration and sanitized handoffs. The workspace is the app on one computer; projects are local folders that go online through their own version control ([version-control](../version-control/SUMMARY.md)).
